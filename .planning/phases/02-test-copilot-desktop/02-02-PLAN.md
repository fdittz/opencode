  <action>
Create a test file that tests the `chat.headers` hook returned by `CopilotAuthPlugin`.

**Setup approach:** The `chat.headers` hook is at `hooks["chat.headers"]` returned by `CopilotAuthPlugin()`. The hook signature is:

```typescript
async (incoming, output) => void
```

Where:

- `incoming` has `{ model: { providerID, api: { npm } }, sessionID }`
- `output` has `{ headers: Record<string, string> }`

The hook:

1. Returns early if `incoming.model.providerID` does NOT include `"github-copilot"`
2. Sets `anthropic-beta` header if `api.npm === "@ai-sdk/anthropic"`
3. Calls `Session.get(incoming.sessionID)` to fetch the session
4. If session has `parentID`, sets `output.headers["x-initiator"] = "agent"`

**Testing strategy:** This requires real Session data in the database, so use `Instance.provide()` and create actual sessions. Follow the pattern from `test/session/session.test.ts`.

**Test cases:**

1. **Subagent session (has parentID) → sets x-initiator: agent**
   - Create a parent session with `Session.create({})`
   - Create a child session with `Session.create({ parentID: parent.id })`
   - Invoke the `chat.headers` hook with `sessionID: child.id` and `model.providerID: "github-copilot"`
   - Assert `output.headers["x-initiator"]` === `"agent"`
   - Clean up both sessions

2. **Regular session (no parentID) → does NOT set x-initiator**
   - Create a session with `Session.create({})`
   - Invoke the hook with `sessionID: session.id` and `model.providerID: "github-copilot"`
   - Assert `output.headers["x-initiator"]` is undefined (not set)
   - Clean up session

3. **Non-copilot provider → returns early, no headers set**
   - Invoke the hook with `model.providerID: "anthropic"` (not copilot)
   - Assert `output.headers` is empty / unchanged
   - (No session needed — hook returns before Session.get)

4. **Session not found → gracefully handles error (no crash)**
   - Invoke the hook with `sessionID: "nonexistent-session-id"` and `model.providerID: "github-copilot"`
   - Assert the hook does NOT throw (`.catch(() => undefined)` handles it)
   - Assert `output.headers["x-initiator"]` is undefined

5. **Anthropic model on copilot → sets anthropic-beta header**
   - Invoke with `model.providerID: "github-copilot"`, `model.api.npm: "@ai-sdk/anthropic"`, a valid session without parentID
   - Assert `output.headers["anthropic-beta"]` === `"interleaved-thinking-2025-05-14"`
   - Assert `output.headers["x-initiator"]` is undefined (no parentID)

**Important conventions:**

- Use `Instance.provide({ directory: projectRoot, fn: ... })` pattern from session.test.ts
- `const projectRoot = path.join(__dirname, "../..")` for the packages/opencode root
- Use `Session.create({})` and `Session.create({ parentID })` for real sessions
- Clean up sessions with `Session.remove()` after each test
- `Log.init({ print: false })` at top level to suppress logs
- Construct minimal mock objects for `incoming` — only the fields the hook accesses need to exist
- The `output` object should be `{ headers: {} as Record<string, string> }`
- The `CopilotAuthPlugin` function takes a `PluginInput` — construct a minimal one
